Request Lifecycle

1
User selects a filter
FilterBar.vue updates one of four reactive refs in the useFilters() composable shared across all views.
2
View component reacts
Each view watches useFilters() refs. Any change triggers loadData(), setting loading.value = true.
3
API client builds request
api.js calls getCurrentFilters(), builds URLSearchParams (skipping 'all' values), and fires an Axios GET to localhost:8001.
4
FastAPI receives & filters
The route handler passes query params to apply_filters() and filter_by_month(), which iterate over in-memory Python lists loaded from JSON at startup.
5
Pydantic validates response
Results are serialized through Pydantic response_model classes (InventoryItem, Order, etc.), returning typed JSON.
6
Vue re-renders
The view stores raw data in ref(), derived values in computed(). Template auto-updates. Loading/error states handled via try/catch.
